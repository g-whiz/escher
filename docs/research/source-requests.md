## 1. Introduction

This file lists every source that the research behind `docs/research/` could not read in full, with what the project needs from it. Section 5.5 of `docs/writing-documentation.md` gives the file this role. The owner uses it to decide what to fetch. An agent uses it to see which claims wait on which source, and what to read when the source arrives.

The owner supplies a source by placing a file in the directory `references/` at the root of the repository. Git ignores that directory, and nothing in it is ever committed (Hard Rule 14 of `AGENTS.md`). An entry leaves this file when an agent reads the source and updates, in the same change, every document that waited on it. A source that the owner supplied and that was read only in part stays with what the documents still need from it, and its Obstacle column says which copy the owner supplied.

A request is high priority when a document says that it blocks a class of signatures, a planned capability of the proof of concept, or a claim that the implementation would rely on. It is medium when it would move claims from secondary to primary status, and low when it is historical or a convenience. Where a document states a priority, this file uses it. Where two documents disagree, it uses the higher one, except that a high rating that a survey of the roadmap gives for its own topic places the request at medium, and a note under the table records the rating. Within a priority, the sources that more documents need come first.

Each citation is given as the documents give it. A missing title, year, or address means that no document records it, and an ellipsis marks a title that the research truncates. Where two documents give different details or priorities, the notes under the table give both.

Accented letters are transliterated to ASCII, as in Poincare, Teichmuller, and De Las Penas, and a title with an American spelling is set in a code span. "Not recorded" means that no document states why the source could not be read.

All ten documents are in `docs/research/`. A citation such as "Section 13.2, G1" points into the named document, and the tag in the code span is the one that document uses for the source. The abbreviations IUC and NEC stand for the International Union of Crystallography and non-Euclidean crystallographic.
